# MaterialGram — нижняя навигация

Рабочая ветка: `fix/navigation-collapse-20261122`

Исходники взяты из Telegram Android commit:
`21f7d109da6ab3506c9e9577f98c6a38771ab335`

## Что лежит в этой папке

- `DialogsActivity.java` — полный исходник с MaterialGram-интеграцией: определяет направление прокрутки основного списка чатов и отправляет панели команду свернуться/развернуться; при возвращении на экран раскрывает её обратно.
- `MainTabsActivity.java` — полный исходник с MaterialGram-интеграцией и реализацией `applyMaterialGramCollapse()`: скрывает все вкладки, кроме выбранной, и раскрывает их при прокрутке вверх или выборе вкладки.
- `MainTabsLayout.java` — полный исходник с поправкой минимальной ширины: одна оставшаяся вкладка больше не растягивает капсулу до 320 dp.
- `GlassTabView.java` — исходник для следующего этапа. Пока без изменений.
- `../tools/prepare_materialgram_upstream.py` — реальный build-патч MaterialGram; он вносит эти изменения в закреплённый upstream при сборке.

## Требование к следующему этапу (подпись только у выбранной вкладки)

Сделать так, чтобы у выбранной вкладки подпись раскрывалась рядом с иконкой, а у невыбранных вкладок оставалась только иконка. Анимация должна быть плавной; ширина капсулы должна пересчитываться по состоянию вкладок. Для этого нужно изучить `GlassTabView.java` и `MainTabsLayout.java`, не менять API наугад и проверить взаимодействие с текущими selected/gesture animations.

## Важная архитектурная деталь

Визуальное сворачивание находится в `MainTabsActivity`, а не в `DialogsActivity`. `DialogsActivity` только сообщает, что основной список чатов прокручивается вниз или вверх. Поэтому для ревью передавай Клоду все четыре Java-файла, а не один `DialogsActivity.java`.

## Проверка

Изменения build-скрипта запускают штатную GitHub Actions сборку на этой ветке. Успешная компиляция не заменяет проверку поведения на устройстве: нужно проверить scroll down/up, переключение вкладок, отображение вкладки Calls/Settings и отключение MaterialGram-панели в настройках.
